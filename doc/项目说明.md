# LangChain Skill Runtime

一个由 uv 管理的 Python 类库，用于把 `SKILL.md` 文件或业务系统中的 Skill 对象编译成 LangChain Agent 可直接使用的 `SkillBundle`。

支持三种输入方式：

- `compile_file()`：直接读取本地或市场提供的 `SKILL.md`，不依赖数据库。
- `compile_objects()`：编译业务系统从数据库、接口或配置中心映射出的 Python 对象。
- `compile()`：保留按 Skill ID 调用 Repository 的兼容方式。

支持四类异构工具：

- Python Function
- 服务端脚本
- 客户端 JavaScript Transport
- MCP：一个 Tool 对象既可兼容绑定单个远端工具，也可连接 MCP Server 并展开其全部工具

最小接入方式：

```python
from langchain_skill_runtime import SkillRuntime
from langchain_skill_runtime.adapters import ToolFactory


runtime = SkillRuntime(
    tool_factory=ToolFactory(
        [function_adapter, script_adapter, client_adapter, mcp_adapter]
    )
)

bundle = await runtime.compile_file("/path/to/SKILL.md")
```

`bundle.system_prompt` 和 `bundle.tools` 可以直接交给 LangChain Agent。源码仓库中的 `doc/技能运行时工具库使用说明.md` 和 `tests/integration/test_library_usage.py` 分别提供完整接入说明与可运行 Demo；测试代码不会进入发行包。
