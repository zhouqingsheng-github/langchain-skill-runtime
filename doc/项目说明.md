# LangChain Skill Runtime

一个由 uv 管理的 Python 类库，用于把数据库中的 Skill、真实 `SKILL.md`、Skill-Tool 关系和异构工具定义编译成 LangChain Agent 可直接使用的 `SkillBundle`。

第一版支持以下工具类型：

- Python Function
- 服务端脚本
- 客户端 JavaScript Transport
- MCP

详细用法参见[技能运行时工具库使用说明](技能运行时工具库使用说明.md)。

测试使用的真实 Skill 文件位于 `tests/fixtures/skills/heterogeneous-tools/SKILL.md`。
