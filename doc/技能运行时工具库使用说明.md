# 技能运行时工具库使用说明

## 一、环境初始化

项目使用 uv 管理 Python、虚拟环境、依赖和构建产物：

```bash
cd /Users/zqs/PycharmProjects/AI/langchain-skill-runtime
uv sync --all-extras --dev
```

核心安装不强制携带 Agent 和 MCP 扩展。业务项目可按需要安装：

```bash
uv add 'langchain-skill-runtime[agent,mcp]'
```

## 二、运行时输入与输出

工具库的输入由三部分组成：

1. `SkillRepository` 返回 Skill 治理主数据和完整 `SKILL.md`。
2. `ToolRepository` 返回已经完成权限过滤和绑定合并的 `ResolvedToolDefinition`。
3. `CompileContext` 提供租户、用户、会话、权限和客户端能力。

输出为 `SkillBundle`：

```python
bundle = await runtime.compile(
    skill_id="hotel-report",
    context=compile_context,
)

print(bundle.system_prompt)
print([tool.name for tool in bundle.tools])
print(bundle.fingerprint)
```

## 三、实现 Repository

核心库不依赖数据库或 ORM，业务系统负责把自己的表结构映射成领域对象：

```python
from collections.abc import Sequence

from langchain_skill_runtime import CompileContext, SkillDefinition
from langchain_skill_runtime.models.tool import ResolvedToolDefinition


class BusinessSkillRepository:
    async def get_skill(
        self,
        skill_id: str,
        context: CompileContext,
    ) -> SkillDefinition | None:
        record = await business_database.get_authorized_skill(
            tenant_id=context.tenant_id,
            user_id=context.user_id,
            skill_id=skill_id,
        )
        if record is None:
            return None
        return SkillDefinition(
            id=str(record.id),
            name=record.name,
            description=record.description,
            content=record.skill_markdown,
            version=record.version,
            enabled=record.enabled,
        )


class BusinessToolRepository:
    async def list_tools(
        self,
        skill_id: str,
        context: CompileContext,
    ) -> Sequence[ResolvedToolDefinition]:
        records = await business_database.list_authorized_skill_tools(
            tenant_id=context.tenant_id,
            user_id=context.user_id,
            permissions=context.permissions,
            skill_id=skill_id,
        )
        return [map_record_to_resolved_tool(record) for record in records]
```

Repository 必须在返回结果前完成租户隔离、用户权限、启停状态和 Skill-Tool 关系合并。核心库不会绕过 Repository 重新查询数据库。

## 四、注册四类 ToolAdapter

### 4.1 Python Function

Python Function 必须先注册，ToolDefinition 只保存 `registry_key`：

```python
from langchain_skill_runtime.adapters.function import PythonFunctionAdapter
from langchain_skill_runtime.executors.function_registry import (
    InMemoryFunctionRegistry,
)


async def calculate_revenue(room_revenue: float, other_revenue: float) -> float:
    return room_revenue + other_revenue


function_registry = InMemoryFunctionRegistry()
function_registry.register("hotel.calculate_revenue", calculate_revenue)
function_adapter = PythonFunctionAdapter(function_registry)
```

核心库不会执行数据库保存的 Python 源码，也不使用 `eval` 或 `exec`。

### 4.2 服务端脚本

业务系统实现受控的脚本执行器：

```python
from collections.abc import Mapping
from typing import Any

from langchain_skill_runtime import CompileContext
from langchain_skill_runtime.adapters.server_script import ServerScriptAdapter


class BusinessScriptExecutor:
    async def execute(
        self,
        artifact_id: str,
        arguments: Mapping[str, Any],
        context: CompileContext,
        timeout_seconds: float,
    ) -> Any:
        return await sandbox_service.execute(
            artifact_id=artifact_id,
            arguments=dict(arguments),
            tenant_id=context.tenant_id,
            timeout_seconds=timeout_seconds,
        )


script_adapter = ServerScriptAdapter(BusinessScriptExecutor())
```

脚本 Executor 负责制品白名单、沙箱、工作目录、资源限制、超时和输出大小控制。

### 4.3 客户端 JavaScript

客户端执行采用 `call_id + asyncio.Future` 等待结果。工具库不创建 WebSocket 服务，业务系统只需注入发送函数：

```python
from langchain_skill_runtime.adapters.client_javascript import (
    ClientJavascriptAdapter,
)
from langchain_skill_runtime.client.models import (
    ClientToolRequest,
    ClientToolResult,
)
from langchain_skill_runtime.client.transport import PendingClientToolTransport


async def websocket_sender(request: ClientToolRequest) -> None:
    connection = connection_registry.get(request.session_id)
    await connection.send_json(request.model_dump(mode="json"))


async def availability_checker(
    session_id: str,
    tool_id: str,
    tool_version: str,
) -> bool:
    return connection_registry.supports(session_id, tool_id, tool_version)


client_transport = PendingClientToolTransport(
    sender=websocket_sender,
    availability_checker=availability_checker,
)
client_adapter = ClientJavascriptAdapter(client_transport)
```

业务 WebSocket 收到客户端结果后交回 Transport：

```python
async def on_client_tool_result(payload: dict) -> None:
    result = ClientToolResult.model_validate(payload)
    await client_transport.accept_result(result)


async def on_client_disconnected(session_id: str) -> None:
    await client_transport.fail_session(session_id)
```

Transport 自动处理并发结果关联、超时、断线、重复响应、迟到响应和会话/工具/版本不匹配。

### 4.4 MCP

MCP Server 配置保存在 ToolDefinition 中，Secret 只保存引用：

```python
from langchain_skill_runtime import CompileContext
from langchain_skill_runtime.adapters.mcp import (
    LangChainMcpToolProvider,
    McpToolAdapter,
)


class BusinessSecretProvider:
    async def resolve(self, reference: str, context: CompileContext) -> str:
        return await secret_service.resolve(
            tenant_id=context.tenant_id,
            reference=reference,
        )


mcp_provider = LangChainMcpToolProvider(
    secret_provider=BusinessSecretProvider(),
)
mcp_adapter = McpToolAdapter(mcp_provider)
```

MCP 配置中的 Secret 引用形式：

```json
{
  "server_name": "hotel-mcp",
  "tool_name": "query_hotel_data",
  "server": {
    "transport": "http",
    "url": "https://mcp.example.com/mcp",
    "headers": {
      "Authorization": {
        "secret_ref": "mcp/hotel/token"
      }
    }
  }
}
```

## 五、创建 SkillRuntime

```python
from langchain_skill_runtime import CompileContext, SkillRuntime
from langchain_skill_runtime.adapters.factory import ToolFactory
from langchain_skill_runtime.models.context import ClientCapability


tool_factory = ToolFactory(
    [
        function_adapter,
        script_adapter,
        client_adapter,
        mcp_adapter,
    ]
)

runtime = SkillRuntime(
    skill_repository=BusinessSkillRepository(),
    tool_repository=BusinessToolRepository(),
    tool_factory=tool_factory,
)

compile_context = CompileContext(
    tenant_id="tenant-1",
    user_id="user-1",
    session_id="client-session-1",
    permissions=frozenset({"hotel:report:read"}),
    client_capabilities=(
        ClientCapability(
            tool_id="client.export.file",
            version="1.0.0",
        ),
    ),
)

bundle = await runtime.compile("hotel-report", compile_context)
```

## 六、装配 LangChain Agent

工具库不持有模型实例和会话历史。业务系统使用编译结果创建 Agent：

```python
from langchain.agents import create_agent


agent = create_agent(
    model=business_model,
    tools=list(bundle.tools),
    system_prompt=bundle.system_prompt,
)
```

## 八、错误和安全规则

- 必需 Tool 构建失败时停止 Skill 编译。
- 非必需 Tool 构建失败时移除并写入 diagnostics。
- Prompt 只声明实际构建成功的 Tool。
- `allowed-tools` 不能创建没有数据库绑定的执行入口。
- 客户端只执行预注册 `tool_key`，不能执行服务端临时下发的 JavaScript 源码。
- Function 只执行 Registry 中的受控函数。
- 服务端脚本只传递制品标识给外部沙箱 Executor。
- MCP Secret 只保存引用，解析值不进入 Prompt 和错误消息。
- `timeout_seconds` 对四类 Tool 统一生效；同步 Python Function 超时后会停止等待，但底层工作线程不能被 Python 强制终止，因此业务函数仍应保证幂等并自行限制外部资源耗时。
- 设置 `output_schema` 后，运行时会在返回 Agent 前校验 Tool 输出；不符合契约的结果不会进入模型上下文。
- `max_output_bytes` 默认限制为 1 MiB，按 UTF-8 JSON 编码后的大小计算，可在 Tool 定义中收紧。
- MCP 暴露给模型的参数严格采用 Repository 中的 `input_schema`，并在编译时检查它与远端 MCP Tool Schema 的兼容性。
- 同一个 Skill 中启用的 Tool 名称必须唯一，并符合 LangChain Tool 名称规则。
- 日志应记录调用标识、工具版本、耗时和状态，不记录敏感参数全文。
