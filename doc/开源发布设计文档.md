# LangChain Skill Runtime 开源发布设计

## 一、发布目标

将 `langchain-skill-runtime` 作为可独立安装、可跨项目使用的 Python 开源工具库发布到公开 GitHub 仓库 `zhouqingsheng-github/langchain-skill-runtime`。

首次开源发布版本为 `0.3.3`，支持从 `SKILL.md`、结构化对象和 Repository 三种来源编译 Skill，并将 Function、Script、Client Transport 和 MCP 工具统一转换为 LangChain Tool。

## 二、开源文件

- `README.md`：中文主文档，作为 GitHub 和 Python 包的默认说明。
- `README_EN.md`：英文文档，与中文文档保持同样的结构和使用边界。
- `LICENSE`：Apache License 2.0 标准全文。
- `.gitignore`：排除 `.idea/`、`.env`、虚拟环境、缓存和构建制品。
- `pyproject.toml`：声明 Apache-2.0、README、源码仓库、Issue 地址和文档地址。

## 三、README 内容边界

中英文 README 均包含：

1. 项目定位与特性。
2. Python 版本、`uv add` 和可选依赖安装方式。
3. `SKILL.md` 最小格式与文件编译示例。
4. Function、Script、Client Transport 和 MCP 四类工具的接入方式。
5. 文件、对象和 Repository 三种 Skill 来源。
6. MCP 工具集动态发现、URL 白名单和 `env` / `secret_ref` 凭据引用。
7. Client Tool 请求通过 Transport 委派并回传结果的流程。
8. 开发、测试、类型检查和格式检查命令。
9. Apache-2.0 许可声明。

README 只展示公开 API 和最小可运行示例，不写入本地绝对路径、真实 Key、特定 IDE 或个人网络环境配置。

## 四、发布安全

- 不提交 `.env`、API Key、Token、Cookie 或包含凭据的 MCP URL。
- 不提交 `.idea/`、`.DS_Store`、`dist/` 和虚拟环境。
- 对全部待提交文件做敏感字段扫描和 Git 差异检查。
- 远程 MCP 凭据在 `SKILL.md` 中只使用 `env` 或 `secret_ref` 引用。

## 五、验收标准

- 中英文 README 相互链接，且安装与使用示例与 `0.3.3` 公开 API 一致。
- `LICENSE` 为未修改的 Apache License 2.0 标准文本。
- `uv run pytest -q`、Ruff 和 Mypy 全部通过。
- 待提交内容不包含真实凭据、IDE 文件或构建制品。
- GitHub 公开仓库默认分支为 `main`，远程代码与本地已验证提交一致。
