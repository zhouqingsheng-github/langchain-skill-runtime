# LangChain Skill Runtime 开源发布实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `langchain-skill-runtime` 0.3.3 以 Apache-2.0 许可证、中英文 README 和完整包元数据发布到公开 GitHub 仓库。

**Architecture:** 保持现有 `src/` 公开 API 不变，根目录的中英文 README 负责面向使用者，`pyproject.toml` 负责 Python 包和 GitHub 项目元数据。发布前通过测试、静态检查、构建验证和敏感信息扫描保证对外仓库可用且不泄漏本地信息。

**Tech Stack:** Python 3.11+、uv、LangChain Core、Pytest、Ruff、Mypy、Git、GitHub。

## Global Constraints

- 公开包版本保持 `0.3.3`。
- 开源许可证使用 Apache License 2.0 标准全文。
- 默认文档为中文 `README.md`，英文文档为 `README_EN.md`。
- 不在 README 中出现本地绝对路径、真实凭据、IDE 或个人网络配置。
- `.env`、`.idea/`、`.DS_Store`、`dist/`、虚拟环境和缓存不得进入 Git 提交。
- 待发布仓库为 `zhouqingsheng-github/langchain-skill-runtime`，默认分支为 `main`。

---

### Task 1: 开源许可与 Python 包元数据

**Files:**
- Create: `LICENSE`
- Modify: `pyproject.toml`
- Modify: `.gitignore`

**Interfaces:**
- Consumes: 现有包名 `langchain-skill-runtime` 和版本 `0.3.3`。
- Produces: GitHub 和 Python 构建工具可识别的 Apache-2.0 许可和项目 URL 元数据。

- [ ] **Step 1: 新增 Apache-2.0 许可证**

在 `LICENSE` 写入 Apache License 2.0 标准全文，开头必须是：

```text
Apache License
Version 2.0, January 2004
http://www.apache.org/licenses/
```

文本必须包含第 1–9 节及附录“How to apply the Apache License to your work”，不添加自定义限制。

- [ ] **Step 2: 补齐 `pyproject.toml` 发布元数据**

将项目 README 改为根目录中文 README，并增加许可、主题和 URL：

```toml
readme = "README.md"
license = "Apache-2.0"
keywords = ["langchain", "skill", "skill-md", "mcp", "tools"]

[project.urls]
Homepage = "https://github.com/zhouqingsheng-github/langchain-skill-runtime"
Repository = "https://github.com/zhouqingsheng-github/langchain-skill-runtime"
Issues = "https://github.com/zhouqingsheng-github/langchain-skill-runtime/issues"
Documentation = "https://github.com/zhouqingsheng-github/langchain-skill-runtime#readme"
```

在 `classifiers` 中增加：

```toml
"License :: OSI Approved :: Apache Software License",
"Operating System :: OS Independent",
"Typing :: Typed",
```

- [ ] **Step 3: 排除本地与敏感文件**

在 `.gitignore` 增加：

```gitignore
.env
.env.*
!.env.example
.idea/
```

- [ ] **Step 4: 验证包元数据**

Run:

```bash
uv build
unzip -p dist/langchain_skill_runtime-0.3.3-py3-none-any.whl '*/METADATA' | rg 'License-Expression: Apache-2.0|Home-page|Project-URL'
```

Expected: wheel 构建成功，METADATA 包含 `License-Expression: Apache-2.0` 和 GitHub Project-URL。

- [ ] **Step 5: 提交许可和元数据**

```bash
git add LICENSE pyproject.toml .gitignore
git commit -m "chore: add Apache-2.0 release metadata"
```

### Task 2: 中英文 README

**Files:**
- Create: `README.md`
- Create: `README_EN.md`

**Interfaces:**
- Consumes: `SkillRuntime.compile_file(...)`、`SkillRuntime.compile_objects(...)`、`SkillRuntime.compile(...)`、`ToolFactory`、四类 Adapter 和 `PendingClientToolTransport.accept_result(...)`。
- Produces: GitHub 访客可直接复制的安装、Skill 编译、MCP 工具集和客户端回传示例。

- [ ] **Step 1: 编写中文 `README.md`**

按以下顺序编写：

```markdown
# LangChain Skill Runtime
[English](README_EN.md) | 简体中文

项目一句话介绍

## 特性
## 安装
## 快速开始
## SKILL.md 工具类型
## 三种 Skill 来源
## MCP 工具集
## Client Transport 结果回传
## 开发与测试
## 安全边界
## 许可证
```

安装命令必须同时包含基础安装和 MCP 可选依赖：

```bash
uv add langchain-skill-runtime
uv add 'langchain-skill-runtime[mcp]'
uv add 'langchain-skill-runtime[agent,mcp]'
```

快速开始必须使用 `InMemoryFunctionRegistry`、`PythonFunctionAdapter`、`ToolFactory` 和 `await runtime.compile_file("skills/calculator/SKILL.md")`。

- [ ] **Step 2: 编写英文 `README_EN.md`**

使用与中文 README 相同的章节顺序，语言切换行必须是：

```markdown
English | [简体中文](README.md)
```

两份 README 的代码、版本、环境变量名、工具类型和安全边界必须一致，不得把 MCP 工具集描述成单个远程 Tool。

- [ ] **Step 3: 检查 README 公开 API 和本地信息**

Run:

```bash
rg -n '/Users/|AMAP_MAPS_API_KEY=.+' README.md README_EN.md
rg -n 'compile_file|compile_objects|PendingClientToolTransport|tools/list|Apache-2.0' README.md README_EN.md
```

Expected: 第一条命令无输出；第二条在两份 README 中都有匹配。

- [ ] **Step 4: 提交中英文 README**

```bash
git add README.md README_EN.md
git commit -m "docs: add bilingual project README"
```
